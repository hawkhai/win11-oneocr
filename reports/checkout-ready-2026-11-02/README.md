逐图测量、27 项比较、模块路径与 Linux 网络证据保存在本目录的 JSON 文件中，汇总为 `summary.json`。固定回归仍按文字、顺序、词切分、手写类别完全一致，以及坐标 1 px、角度 0.1 度、置信度 `1e-3` 验收。三个错误契约不计为识别成功。

Windows 包包含 VC 14.44 release CRT，要求 Windows 10/11 x64 的系统 UCRT；Linux 包要求 glibc 2.43 或更新。macOS、Android、ARM64 没有可直接执行且经过验证的预编译文件，继续标记为未验证。模型所有权声明不变；本轮没有 push 或发布。
