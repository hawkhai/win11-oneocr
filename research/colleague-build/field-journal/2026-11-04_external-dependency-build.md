# 外部依赖构建边界

用户要求同事能够编译，并明确依赖可自行取得和编译，不能把太多二进制加入 Git。应提供完整源码、依赖锁定、路径参数和清晰命令；不能把“可编译”自行扩张成“把所有依赖包塞进 Git”。

E-001/E-002 → F-001/F-002 → P-001：SDK 模式无需研究 Python/WSL，缺依赖明确报错；在全新源码目录显式提供已准备的外部依赖，两端构建/CTest 和各 269 项严格比较通过。依赖、编译缓存和二进制只留在忽略目录；历史运行包不改写。

本地提交文本源码、脚本、说明和报告，刷新最终 HEAD 离线包后按 AGENTS 收手。不上传社区，也不主动继续扩展范围。
