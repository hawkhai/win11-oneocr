# 2026-11-03：退化曲线与长行边界

授权：当前会话明确要求本地离线逆向、补齐源码、增加样本、严格回归及本地 commit；不 push 或上传。固定 reverse-skill 路由 R22，Ghidra 11.3.2 headless + JDK 21，单代理承担静态、动态和验证角色。

静态分析先比较旧版与 Photos 版调用链，再用版本锁定的独立子进程调用内部函数。备用 SVD 是对正规方程求解，切换条件为 LU 零主元；不能将数学上的秩亏直接等同于浮点 LU 失败。近奇异输入单独保留，避免“改进”求解器导致与 DLL 不一致。

归一化上限分支不能按通常的多边形剪裁理解。实际目标顶点尾部保持零，截断端点只决定输出宽度，原始源顶点和三角形仍全部保留。原像素与词框预言机证明该路径；新增弯曲、偏移源多边形也通过。场景 PNG 与内部几何测试分别统计，未声称默认 1152×768 的端到端长图必然触发归一化最大宽度。

10000×140 PNG 初次在 Windows 源码端产生 627 项差异。逐阶段张量比较定位到检测器预处理，输入最大差为 197.31444；DLL 的面积比例插值映射在 0.04 处切换 AREA/LINEAR。修复后输入逐元素一致，整图严格比较为零差异。最初失败输出保存在报告 diagnostics，不删除或改写。

Wasm 预加载测试最初曾因启动目录找不到 data 而提前退出；仅检查零退出码不足以证明执行到 main。构建脚本现在指定测试目录，并同时要求 C++ 成功标记。CMake 的重复 preload 选项合并也按成组选项修复。最终 Wasm 分支测试包含 7 组归一化、56 组词框及原 DLL 的长图输入，不能用早期构建日志替代。
